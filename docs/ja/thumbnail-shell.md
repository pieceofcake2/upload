# サムネイルシェル

<a id="what-it-does"></a>

## できること

このシェルは、データベースから画像を探し、モデルの Upload ビヘイビアの設定にもとづいてサムネイルを
再生成します。これで、サムネイルの設定を変更してからシェルを実行すれば、画像を再アップロードせずに
画像を更新できます。

<a id="how-it-works"></a>

## 仕組み

シェルは指定されたモデルを受け取り、Upload プラグインがあって設定されていることを確認します。
次に、すべての画像を順に処理し、設定されたアップロードのフィールドがデータベースで値を持っていること、
そしてファイルがファイルシステム上に存在することを確認します。そのうえで、現在のモデルの設定を使って
サムネイルを再生成します。

<a id="running-the-shell"></a>

## シェルの実行

ほかの cake のシェルと同じように、コマンドラインからシェルを実行できます。

```bash
bin/cake Upload.thumbnail generate

# legacy layout
app/Console/cake Upload.thumbnail generate
```

どのモデルを処理するかを尋ねられ、その後シェルが画像を処理します。モデルは `Upload.Upload`
(または `Upload.FileImport`) ビヘイビアを使っている必要があります。
